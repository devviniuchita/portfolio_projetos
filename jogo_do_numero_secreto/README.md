# Jogo do Número Secreto

Bem-vindo ao **Jogo do Número Secreto**! Este é um jogo simples onde o objetivo é adivinhar um número secreto gerado aleatoriamente entre 1 e 100. O jogo foi desenvolvido utilizando HTML, CSS e JavaScript, e é uma ótima maneira de praticar suas habilidades de adivinhação!

## Como Jogar

1. **Iniciar o Jogo**: Ao abrir o jogo, você verá uma mensagem pedindo para escolher um número entre 1 e 100.
2. **Fazer um Chute**: Digite um número no campo de entrada e clique no botão "Chutar".
3. **Receber Feedback**: O jogo informará se o número secreto é maior ou menor que o seu chute.
4. **Adivinhar o Número**: Continue chutando até acertar o número secreto.
5. **Reiniciar o Jogo**: Após acertar, você pode reiniciar o jogo clicando no botão "Novo jogo".

## Funcionalidades

- **Geração Aleatória de Números**: O número secreto é gerado aleatoriamente a cada rodada.
- **Feedback Instantâneo**: O jogo informa se o número secreto é maior ou menor que o seu chute.
- **Contagem de Tentativas**: O jogo conta quantas tentativas você levou para acertar o número secreto.
- **Reinicialização**: Você pode reiniciar o jogo a qualquer momento após acertar o número secreto.

## Tecnologias Utilizadas

- **HTML**: Estrutura da página do jogo.
- **CSS**: Estilização da interface, incluindo cores, fontes e layout responsivo.
- **JavaScript**: Lógica do jogo, incluindo geração de números aleatórios, validação de chutes e feedback ao usuário.
