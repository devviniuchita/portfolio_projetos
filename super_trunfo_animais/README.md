Bem-vindo ao **Super Trunfo de Animais**! Este jogo é inspirado no clássico jogo de cartas Super Trunfo, mas com toques especiais:

- **Todas as cartas representam animais com atributos únicos** de **Ataque**, **Defesa** e **Velocidade**.

- O **Sistema de Batalhas** é de: **Dupla vs Dupla**.

Prepare-se para mergulhar em um mundo de estratégia e diversão!</br></br>

## 🎮 Como Jogar

1. **Distribuição das Cartas**:

   - São sorteadas 4 cartas: 2 para o **Jogador** e 2 para a **Máquina**.
   - Cada carta representa um animal com três atributos: **Ataque**, **Defesa** e **Velocidade**.

2. **Escolha do Atributo**:

   - O jogador escolhe um dos três atributos para comparar (**Ataque**, **Defesa** ou **Velocidade**).
   - O valor do atributo escolhido é **somado nas duas cartas** do Jogador e nas duas cartas da Máquina.

3. **Comparação**:

   - O jogador com a maior soma no atributo escolhido vence a rodada.
   - Em caso de empate, a rodada é considerada empatada.

4. **Combinações**:
   - O jogo possui **27 cartas de animais**, permitindo **17.550 combinações diferentes** de partidas. Cada jogo é uma nova experiência!

## 🛠️ Instalação

Para rodar o jogo localmente, siga os passos abaixo:

1. **Clone o repositório**:

   ```bash
   git clone https://github.com/devviniuchita/portfolio_projetos/tree/main/Projetos/super_trunfo_animais

   ```

2. **Entre na pasta**:

   ```bash
   cd super_trunfo_animais

   ```

3. **Abra o arquivo index.html no seu navegador**:
   ```bash
   start index.html  # No Windows
   open index.html   # No macOS
   ```
